## Getting Started

```sh
# Add OpenSelena Tap
brew tap OpenSelena/tap
```

### Available Tools

#### 1. OmniGet (Desktop App)
Universal desktop media workstation (macOS Apple Silicon & Intel).
```sh
brew install --cask omniget
```

#### 2. Open Omni (CLI)
Terminal media downloader & TUI for 1,800+ sites with batch playlist processing.
```sh
brew install open-omni
```

#### 3. Open Nami (CLI)
Bulk media profile archiver for Instagram, TikTok, Facebook, and X.
```sh
brew install open-nami
```
